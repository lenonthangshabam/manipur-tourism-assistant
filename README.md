# Manipur Tourism Assistant

A Streamlit prototype for a multilingual tourism chatbot focused on Manipur.

## Features
- Tourism knowledge base
- Place search and category recommendations
- Food information
- Local etiquette tips
- Accommodation and transport guidance
- Directions/location guidance
- Emergency information placeholder
- 1/2/3-day trip planner
- Sample budget planner
- English/Hindi/Meitei-script language detection
- Browser microphone input with speech-to-text for English/Hindi

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt`.
3. In Streamlit Community Cloud, choose the repository and set `app.py` as the entrypoint.
4. Deploy.
